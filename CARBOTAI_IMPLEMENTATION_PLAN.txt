--------------------------------------------------------------------------------
OBJECTIVE
--------------------------------------------------------------------------------

Build a cloud-native, multi-tenant SaaS platform for used car dealerships using
the MERN stack, Docker, Kubernetes, and modern system design principles.

The platform automates customer engagement through an AI-powered WhatsApp
chatbot, manages car inventory with intelligence, tracks and converts leads,
runs multi-channel marketing campaigns, generates GST invoices, and delivers
advanced business analytics — all serving multiple showroom tenants on a single
shared infrastructure.

This task tests your backend microservices skills, multi-tenant system design,
WhatsApp API integration, AI/NLP implementation, event-driven architecture,
frontend integration, and full-stack MERN proficiency.


--------------------------------------------------------------------------------
WHAT ARE WE ACTUALLY BUILDING?
--------------------------------------------------------------------------------

CarBot AI is an all-in-one SaaS platform that replaces the fragmented, manual
tools used by Indian used car showrooms. Today, showroom owners use WhatsApp
manually, track inventory on Excel, manage leads on paper, and generate invoices
in Word. CarBot AI unifies all of this into one intelligent platform that
showrooms subscribe to and use immediately — no developer required.


THREE ACCESS POINTS:

  1. Super Admin Panel   (admin.carbotai.in)
     You (platform owner). Manage all tenants, assign plans, activate/deactivate
     access, configure WhatsApp credentials per showroom.

  2. Showroom Admin Panel  (panel.carbotai.in)
     Showroom owners. Manage their own inventory, leads, appointments, campaigns,
     billing, and analytics.

  3. WhatsApp Chatbot  (one per showroom, on their own WA number)
     End customers (car buyers). Search cars, get EMI quotes, and book test
     drives — all through WhatsApp chat.


MULTI-TENANCY MODEL:

  - Every showroom is a Tenant. They get their own scoped data, their own
    WhatsApp bot number, and a subdomain for their public website.
  - A single backend handles ALL showrooms. The phone_number_id from WhatsApp
    identifies which showroom a message belongs to.
  - Subscription is manual — No payment gateway. The showroom owner pays via
    UPI or bank transfer, then contacts the Super Admin. The Super Admin logs
    the payment note, selects a plan, and activates the showroom's access from
    the Super Admin Panel.

PLANS:

MICROSERVICES — WHAT EACH SERVICE DOES
--------------------------------------------------------------------------------

1. AUTH SERVICE
   The identity and access backbone of the entire platform.
   - Handles showroom registration and login.
   - Issues JWT tokens (separate tokens for showroom users and super admin).
   - Stores Tenant records, TenantUser (staff) records, and SuperAdmin account.
   - Super Admin uses this service to activate/deactivate showroom access,
     assign plans (Basic/Pro/Enterprise), and set access expiry dates.
   - All other services check tenant access via shared middleware from here.

2. INVENTORY SERVICE
   Manages the complete lifecycle of every car in every showroom.
   - Full car CRUD — add, edit, delete, list cars.
   - Stores VIN number, RC details, insurance policy, and service history.
   - Handles image/video uploads to Cloudinary (up to 20 images, walkaround
     video, and 360-degree spin image sets).
   - Tracks "Days in Inventory" — how long a car has been sitting unsold.
   - Sends aging alerts (30 / 60 / 90 days) via the message broker.
   - Tracks insurance expiry and alerts the owner before it lapses.
   - Calculates profit margin: sold price minus purchase price, repair costs,
     and other expenses.
   - Calls Gemini AI to suggest a competitive market price for each car.

3. WHATSAPP BOT SERVICE
   Handles all incoming WhatsApp customer conversations across all showrooms.
   - One webhook URL receives messages from all registered showroom numbers.
   - Routes each message to the correct showroom using phone_number_id.
   - Maintains a conversation state machine per customer (IDLE > MENU >
     SEARCH > VIEW RESULTS > CAR DETAIL > BOOK > CONFIRM > IDLE).
   - Uses Gemini AI (NLP) to understand natural language queries like
     "diesel SUV automatic under 10 lakh 2020 onwards".
   - Uses Fuse.js for fuzzy matching — handles spelling mistakes like
     "creata" -> "Creta" or "disel" -> "Diesel".
   - Provides an EMI calculator directly in chat.
   - Handles test drive booking and saves appointments to the database.
   - Automatically sends follow-up messages on Day 1, Day 3, and Day 7.
   - If a showroom's subscription is expired, the bot replies with a polite
     "bot inactive" message and stops processing.

4. LEAD & CRM SERVICE
   Captures and tracks every customer inquiry from every channel.
   - Automatically creates a lead when a new customer contacts the bot.
   - Also captures leads from website forms, Facebook ads, and walk-ins.
   - Prevents duplicates — same phone number updates the existing lead.
   - Auto-scores every lead as Hot (>=60), Warm (30-59), or Cold (<30)
     based on their engagement (test drive booked = +30 pts, etc.).
   - Tracks the pipeline stage: New > Contacted > Test Drive > Negotiation
     > Closed / Lost.
   - Lets staff assign leads to agents, log calls, and set follow-up dates.
   - Shows overdue follow-ups with a red badge on the dashboard.

5. CAMPAIGN SERVICE
   Runs marketing campaigns across WhatsApp and Email channels.
   - Create a campaign: pick audience (all leads / hot leads / cold leads /
     old customers), write message with {name} personalization, schedule it.
   - Sends WhatsApp campaigns using the showroom's own WA credentials.
   - Tracks delivery: Sent / Delivered / Read / Failed per recipient.
   - Has a pre-loaded festival calendar (Diwali, Eid, Christmas, etc.) and
     auto-drafts a campaign 3 days before each festival for preview.
   - When a new car is added, it matches the car to leads who searched for
     similar cars and lets the owner send a "New Arrival" broadcast.
   - Sends email campaigns via Resend/Nodemailer with open-rate tracking.
   - Supports old customer remarketing (6-month / 1-year re-engagement).

6. BILLING & ERP SERVICE
   Replaces the showroom's paper-based billing with digital tools.
   - Generates GST-compliant invoices as PDF (CGST/SGST for intra-state,
     IGST for inter-state) — downloaded or sent via WhatsApp/email.
   - Auto-sequential invoice numbers: INV-2026-001, INV-2026-002, etc.
   - Generates vehicle delivery notes when a car is marked as sold.
   - Tracks overhead expenses (rent, salaries, advertising, utilities).
   - Tracks per-car variable expenses (repair, transport, etc.) which feed
     into the profit margin calculation.
   - Produces monthly sales reports, GST reports, and per-car P&L reports.

7. ANALYTICS SERVICE
   Aggregates data from across the platform into business intelligence dashboards.
   - Revenue dashboard: monthly revenue charts, average sale price, revenue
     by car type (Sedan / SUV / Hatchback).
   - Sales funnel: conversion rates at each pipeline stage, drop-off analysis.
   - Agent productivity: calls made, deals closed, conversion rate per agent.
   - Marketing ROI: leads generated vs. cost per campaign, best channel.
   - Inventory intelligence: avg days-to-sell, slow-moving stock, demand
     heatmap (which models are most searched in which city).
   - Super admin view: platform MRR, ARR, churn rate, plan distribution,
     top tenants, geographic distribution of showrooms.

8. NOTIFICATION SERVICE
   A dedicated dispatcher — it only sends notifications, never initiates them.
   - Listens to ALL domain events from the message broker (RabbitMQ/Kafka).
   - appointment.booked  -> WhatsApp confirmation to customer + email to owner.
   - lead.assigned       -> WhatsApp alert to the assigned sales agent.
   - car.aging_alert     -> WhatsApp alert to showroom owner about old stock.
   - insurance.expiring  -> WhatsApp alert to showroom owner before expiry.
   - invoice.created     -> WhatsApp PDF to buyer + email to showroom owner.
   - lead.scored (Hot)   -> WhatsApp to agent: "Hot lead! Call now."
   - Uses an idempotency key to prevent sending the same notification twice.
   - Failed notifications go to a dead-letter queue and are retried with
     exponential backoff.

9. API GATEWAY
   The single entry point — no service is directly exposed to the internet.
   - Routes every request to the correct microservice by URL prefix.
   - Validates JWT on all protected routes before forwarding the request.
   - Injects tenant_id from the JWT into request headers for all services.
   - Blocks plan-restricted features (e.g., campaigns blocked for Basic plan).
   - Rate-limits requests to prevent abuse.
   - Logs every request with tenant_id + trace_id for distributed tracing.

10. WEBSITE BUILDER SERVICE  [Optional — Pro / Enterprise Plan]
    Auto-generates a branded, SEO-optimized public website for each showroom.
    - Serves showroom websites at {slug}.carbotai.in (e.g., haripriya-cars.carbotai.in).
    - Supports custom domains with automatic SSL via Let's Encrypt.
    - Stays in sync with inventory by consuming car.added / car.sold events.
    - Server-side rendered (Next.js) so Google can index every car listing.
    - Each car gets its own SEO page with Schema.org Vehicle markup.
    - Website contact forms feed leads directly into the CRM Service.
    - Includes a floating WhatsApp chat widget, Google Reviews widget,
      featured car carousel, and a blog section.
